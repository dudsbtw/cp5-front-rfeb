Política de Privacidade

O Melodia é um projeto acadêmico. Esta página explica o que acontece com as informações digitadas no formulário de demonstração.

O que o formulário faz

O nome, o e-mail e a confirmação de leitura da política são verificados apenas no seu navegador. Os dados não são enviados a um servidor, guardados ou usados para mandar mensagens. Depois de uma validação bem-sucedida, os campos são limpos.

Recursos externos

O site carrega Google Fonts, Tailwind CSS, Font Awesome e retratos ilustrativos por serviços externos. Seu navegador faz conexões a esses serviços para carregar os arquivos necessários à página.

Se o projeto mudar

Antes de ativar um cadastro real, esta política precisará informar como os dados serão coletados, usados e excluídos.
